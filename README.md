# 🎓 Smart Campus – Digital Campus Management System

## 📌 About the Project

**Smart Campus – Digital Campus Management System** is a web-based application designed to simplify and digitize campus activities through a single platform. It brings essential campus services together to help students, faculty, and administrators access and manage information efficiently.

The system provides a centralized platform for managing student records, faculty details, courses, attendance, classrooms, transportation, library resources, events, achievements, and campus support services.

## ✨ Features

- 📊 **Dashboard** – Access campus information from one place.
- 🎓 **Student Management** – Manage student information and records.
- 👨‍🏫 **Faculty Management** – Organize faculty details.
- 📚 **Course Management** – View and manage course information.
- 📅 **Attendance Management** – Manage student attendance.
- 🏫 **Classroom Management** – Organize classroom information.
- 🚌 **Transport Management** – Access campus transportation details.
- 📖 **Library Management** – Manage library resources and book information.
- 🎉 **Events** – Display campus events and activities.
- 🏆 **Achievements** – Showcase student and campus achievements.
- 🌱 **Green Campus** – Promote eco-friendly campus initiatives.
- 🆘 **Emergency & Support** – Provide quick access to campus support.
- 🤖 **Smart Campus Assistant** – An interactive assistant for campus-related queries.
- ⚙️ **Settings** – Access application settings.

## 🛠️ Technologies Used

- **HTML5** – Structures the web pages.
- **CSS3** – Provides styling and layout.
- **JavaScript** – Adds interactivity and dynamic functionality.
- **SQL** – Stores and manages structured campus data.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Explore the dashboard and available campus management sections.

### Database Setup

The repository includes `smart_campus.sql` for database setup.

1. Open MySQL Workbench or another compatible SQL client.
2. Import or execute `smart_campus.sql`.
3. Configure the database connection in your application if required.

**Note:** Database setup is necessary only if the application code connects to MySQL. A static website will not connect to MySQL directly without a suitable backend or database service.
